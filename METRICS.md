# Metrics

## North Star Metric

Completed AI Audits Per Week

This metric matters because it directly measures how many users are actively analyzing and optimizing their AI spending.



## Input Metrics

### 1. Report Downloads
Shows how many users found value in the audit.

### 2. Tool Entries Created
Measures engagement depth inside the dashboard.

### 3. Returning Users
Indicates whether users continue tracking AI spending over time.



## What I’d Instrument First

- Audit completion rate
- Average tools added per audit
- Download report clicks
- Currency selection usage
- Recommendation acceptance trends



## Pivot Trigger

If fewer than 10% of users complete an audit after entering tool data, the onboarding and UX would need redesign.

If retention stays extremely low after multiple iterations, the product positioning would need adjustment.
