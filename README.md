# AI Spend Audit Dashboard

AI Spend Audit Dashboard helps users track and optimize AI subscription spending.

The tool analyzes monthly AI expenses, provides savings recommendations, visualizes spending using charts, and generates downloadable audit reports.


# Features

- AI subscription tracking
- Savings recommendations
- Currency selector
- Pie chart analytics
- AI efficiency score
- Downloadable audit report
- Dynamic tool management


# Tech Stack

- Next.js
- React
- TailwindCSS
- Recharts
- TypeScript


# Run Locally

```bash
npm install
npm run dev
```

# Deployment
https://ai-spend-audit-dun.vercel.app

# Decisions

1. Used localStorage instead of a backend database for simplicity.
2. Used Recharts for easy chart visualization.
3. Added currency selector for global accessibility.
4. Used TailwindCSS for rapid UI development.
5. Added downloadable reports for usability.
