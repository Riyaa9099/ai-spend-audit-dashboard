# AI Spend Audit Dashboard

AI Spend Audit Dashboard is a web application that helps startups and teams analyze AI subscription spending, identify savings opportunities, and optimize tool usage.

The dashboard provides spending analytics, recommendations, AI efficiency scoring, downloadable reports, and visualization charts.

---

# Features

- AI subscription tracking
- Savings recommendations
- Monthly & yearly savings analytics
- Currency selector
- AI efficiency score
- Pie chart visualizations
- Downloadable audit reports
- Responsive modern UI

---

# Tech Stack

- Next.js
- React
- Tailwind CSS
- Recharts

## Install dependencies

```bash

```

## Run locally

```bash
npm run dev
```

## Build project

```bash
npm run build
```

# Decisions & Trade-offs

1. Used LocalStorage instead of database for simplicity.
2. Chose Recharts for fast visualization integration.
3. Used frontend-only calculations to reduce backend complexity.
4. Focused on responsive UI over authentication features initially.
5. Added downloadable reports instead of email-based exports.
