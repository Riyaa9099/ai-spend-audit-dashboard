# Reflection

## 1. Hardest Bug

The hardest bug was handling recommendation calculations correctly when users entered empty values or changed currencies. Initially, the calculations returned incorrect totals and sometimes displayed NaN values. I debugged this by checking how Number() conversion worked and adding fallback conditions. I tested different user inputs manually and verified calculations step-by-step until the issue was fixed.



## 2. Decision I Reversed

Initially, I planned to create a very minimal dashboard without charts. Mid-week, I realized visual analytics would make the tool more useful and professional. I added pie charts and AI efficiency scoring to improve user understanding and engagement.



## 3. What I Would Build Next

In week 2, I would add authentication, database storage, team collaboration, and real-time pricing APIs. I would also generate advanced AI recommendations using OpenAI APIs and allow users to compare spending trends historically.



## 4. How I Used AI Tools

I used ChatGPT for debugging React issues, improving UI structure, generating documentation drafts, and refining logic. I did not fully trust AI-generated code without testing it myself. One specific issue was when AI generated invalid JSX structure that caused compilation errors. I manually debugged and corrected the component structure.
